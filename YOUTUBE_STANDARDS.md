# YouTube standards for MarketRadar Whale videos (T50-08)

Checked LIVE at the official pages on 2026-11-03 (UTC) by the lane2-video worker. Enforced by `instagram-bot/v2/standards-check.mjs`
(runs in `.github/workflows/yt-v2.yml` before every upload and in `yt-samples.yml`). A FAIL means the video is not uploaded.
Re-check the sources when a rule looks out of date (R10/R61); change the script and this file together.

| # | Rule | Source (official) | What the check script tests |
|---|------|-------------------|-----------------------------|
| a | **Inauthentic content** (renamed from "repetitious content" on 15 July 2025) and **reused content** (YPP monetization). Not allowed: "similar or repetitive content with low educational value", "image slideshows, templated storylines or scrolling text with minimal or no narrative", "AI-generated content made with generic or unoriginal templates". Allowed: same intro/outro when most of the content differs; series where each video has its own storyline. | https://support.google.com/youtube/answer/1311392 | at least 3 distinct real numbers in the narration (own data); every sentence has its own picture (unique picture keys); `similarity-gate.mjs` blocks a video whose title, script or picture is too close to the last uploads |
| b | **Altered or synthetic content** disclosure: needed only for *realistic* content (a real person saying something they did not, altered real footage or events, realistic scenes that never happened). Non-realistic animation and AI help for infographics/thumbnails do not need it. Our videos: real chart data, animated cartoon mascot, text-to-speech narrator (not a clone of a real person) = not required; we still say it in the description and set the API flag (`status.containsSyntheticMedia`, Data API revision 2024-10-30) to be safe; disclosure "won't limit a video's audience or impact its eligibility to earn money". | https://support.google.com/youtube/answer/14328491 ; https://developers.google.com/youtube/v3/revision_history | description has "synthetic voice" + "animated mascot"; `upload.mjs` sets `containsSyntheticMedia` and `selfDeclaredMadeForKids: false` |
| c | **Spam, deceptive practices, misleading metadata**: titles, thumbnails, descriptions that trick viewers into content that does not deliver what was promised are banned (malicious clickbait). Brand rule R53: no venue/exchange names. | https://support.google.com/youtube/answer/2801973 | title 11-100 chars (Shorts 88 + " #Shorts"); no clickbait word list; max 2 all-caps words; every number in the title appears in the video; no venue names in title/description/voice |
| d | **Financial content**: education only, never investment instructions (our own rule; YouTube has no separate finance-disclaimer rule, it falls under misleading/harmful content). | MarketRadar rule (owner), R55 | "not financial advice" in description (and narration for long videos); no "buy now / sell now / guaranteed profit" |
| e | **Upload encoding**: MP4, moov atom at the front (fast start), no edit lists; H.264 High profile, 4:2:0, frame rate kept as recorded (constant 24/25/30/48/50/60); closed GOP of half the frame rate; AAC-LC (or Opus), 48 kHz. SDR bitrate 1080p: 8 Mbps at 24-30 fps, 12 Mbps at 48-60 fps. | https://support.google.com/youtube/answer/1722171 | ffprobe: h264 High, yuv420p, r_frame_rate = avg_frame_rate, aac LC 48000 Hz, moov before mdat, video bitrate 3-14 Mbps (render target 8 Mbps; still frames compress lower) |
| e | **Shorts**: square or vertical, up to 3 minutes (since 15 Oct 2024). We render 1080x1920 (9:16). Long videos 1920x1080 (16:9). | https://support.google.com/youtube/answer/15424877 | Short 1080x1920 and <= 180 s; long 1920x1080 |
| e | **Thumbnails**: 16:9, min width 640 px, JPG/PNG, up to 2 MB on mobile (50 MB desktop). Custom Shorts thumbnails only in Studio on a computer (API cannot). We use 1280x720 PNG < 2 MB. | https://support.google.com/youtube/answer/72431 | long: thumbA + thumbB exist, 1280x720, < 2 MB |
| f | **Loudness**: YouTube normalizes playback to about -14 LUFS [estimate: industry measurement, not an official YouTube page]. We master to -14 LUFS integrated, true peak <= -1.5 dBTP (2-pass linear loudnorm), so nothing clips and YouTube does not turn us down. | (industry practice; no official page) | ffmpeg loudnorm measure: -14 +- 1.5 LUFS, true peak <= -1.0 dBTP |
| g | **One sentence = one visual** (owner 2026-10-30 11:35Z long, 14:35Z Shorts): every spoken sentence is shown at that moment: the number/wallet/key words as a big callout, the entry/now/liquidation/ROE part of the chart ringed in yellow, never a static unchanged frame. Implemented in `instagram-bot/v2/visual.mjs` (+ `v3.mjs`, `xchart.mjs` focus, `scene.html` .kw). | owner rule (T50-08) | every step has a callout; no two steps in a row with the same picture; every spoken number appears in that sentence's callout; voice timeline = video length |
| h | **Documentary style v5 (owner 2026-11-03 21:42Z "real images, not animation")**: sentences with a chart focus (and long-video sentences with numbers) show our own data shot; other sentences show a licensed stock photo full-screen with kicker + callout; every step moves (slow zoom/drift); no mascot. Allowed pictures only: Pexels License (https://www.pexels.com/license/), Pixabay Content License (https://pixabay.com/service/license-summary/; no recognisable brands/logos in commercial use, no misleading use), Openverse CC0 / public-domain mark only (https://openverse.org), Wikimedia Commons CC0 / public domain / CC BY (attribution in the description). CC BY-SA, news photos, logos and other creators' clips are NOT allowed. Every photo is logged in `<video>-credits.json` (provider, license, author, source page) and the description says "licensed stock photos". Real photos are not altered to show events that did not happen, so no extra synthetic flag beyond the existing containsSyntheticMedia (voice); if an AI-generated realistic image is ever used, the flag stays true. Implemented in `v2/stock.mjs`, `v2/v3.mjs` (style doc), `v2/make.mjs --style=doc` (default). | owner rule (T50-08) + provider license pages | `standards-check.mjs` rules h: no mascot, allowed license + https source per photo, credits file complete, CC BY credited in description, long >= 25% photo steps, Shorts >= 2 |
